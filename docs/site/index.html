Web 端

在本机启动 Whistle，通过浏览器使用面板，无需安装桌面应用。

查看 Web 端源码 ↗
启动步骤
  1. 安装 Node.js 20+（含 npm），下载 Web 端源码并解压。
  2. 在工具目录打开终端，执行：
    npm install -g whistle
cd whistle.cafe-projects
npm link
w2 start -H 127.0.0.1 -p 8899
  3. 打开 本地项目面板，在体检中选择工作区，配置浏览器代理与证书，再启动项目。Whistle 已运行时执行 w2 restart 加载插件。

关闭标签页后服务仍会运行。结束时先在面板停止项目，再执行 w2 stop。Web 端界面和功能以 __WEB_BRANCH_LABEL__ 分支为准。

请先安装 Node.js 20+（含 npm）。桌面端自动补装缺少的 Whistle；Web 端按启动步骤安装。

桌面端使用说明

三步，进入开发状态。

阅读完整说明 ↗
  1. 01

    安装并打开

    安装 Node.js 和桌面端，应用会自动准备 Whistle，无需手动打开终端。

  2. 02

    选择项目目录

    选择项目所在目录，工具会自动识别工作区、扫描子项目并生成列表。目录与最近记录会自动保存。

  3. 03

    启动，打开项目页面

    在体检中完成依赖、证书和代理配置。启动项目后，打开测试页面检查「本地接管」徽标。

你可能想知道

需要配置浏览器代理吗？＋

根据体检提示选择接入方式。浏览器代理设置位于「体检 → Advanced」，旁边的 ⓘ 提供 ZeroOmega 安装及分流说明。只将测试域名的 18443 端口指向 127.0.0.1:8899，其他流量沿用你的配置。退出应用后，将扩展切回系统代理。

macOS 提示 Apple 无法验证应用，怎么办？＋

当前安装包尚未经过 Apple 公证。确认来自本项目后，打开「系统设置 → 隐私与安全性」，在应用拦截提示旁选择「仍要打开」。请参阅 Apple 官方说明。

关闭应用，服务会一起停止吗？＋

桌面端会清理工具启动的项目服务与终端任务，恢复工具修改的代理，并停止工具启动且仍由它管理的 Whistle。Web 端关闭标签页后服务继续运行，需在面板停止项目，再执行 w2 stop。

为什么安装包或完整说明需要登录？＋

如果仓库设为私有，需要使用有权限的 GitHub 账号查看说明和下载 Release。官网公开展示不改变仓库与安装包的访问权限。
